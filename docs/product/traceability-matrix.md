# Traceability Matrix

Maps each important requirement to its implementation phase, component, planned test levels, and evidence. Evidence is filled only with tests that actually ran and passed, in the same change that produces them. Phase 01 evidence is in [phase-01-foundation-data.md](../phases/phase-01-foundation-data.md). Phase 02 evidence is in [phase-02-analytics-engine.md](../phases/phase-02-analytics-engine.md). Phase 03 evidence is in [phase-03-backend-api.md](../phases/phase-03-backend-api.md).

Independent Phase 02 audit evidence is recorded in that phase document under "Independent Analytics Audit". `audit_test.go` covers recovery continuity (FR-DET-007/BR-03), ratio overflow and independent confidence votes (FR-DET-005/006, BR-02/05), coherent current support (BR-04), baseline feedback and cold start (FR-DET-002/004), exact episode/event boundaries, and status/priority semantics. Extended dataset tests verify complete evidence under a whole-day shift and renaming (ER-01/02), coherent relative-threshold sensitivity, and the explicit gap-sensitivity limitation. Final executed regression: 113 unit tests + 76 subtests; 127 integration/black-box tests + 83 subtests; zero failures or skips. The audit's source-CSV recomputation independently matches all signal baselines/Z and finding aggregates (FR-AI-002/BR-07).

Levels: **U** unit · **I** integration (real PostgreSQL / API) · **F** functional/E2E (Playwright, or API-level acceptance in Phase 03) · **V** visual/manual review · **R** repository/review check.

Independent Phase 03 audit evidence is in the phase document under "Independent Backend Audit". Auth and HTTP audit tests cover strict whole-body login parsing, signed-token lifetime bounds, safe panic logging, concurrent request IDs and canonical source timestamps (FR-AUTH-001, FR-API-001). Real PostgreSQL audit tests cover claim-time engine provenance, source snapshots, preserved source data on migration rollback, failure recovery, all three current-state API families, literal search, bounded reading history, evidence round trips and zero-finding confidence (FR-ANL-001/003, FR-DATA-001, FR-MTR-001–005, FR-ANOM-001, FR-INV-001, FR-DASH-001). Executed uncached regression: 154 unit tests + 89 subtests; 199 integration/black-box tests + 124 subtests; zero failures or skips, including shuffled runs.

Status: `Planned` → `In Progress` → `Verified`.
